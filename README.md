# Budget Tracker Pro

Website budget tracker kompleks berbasis HTML/CSS/JS tanpa dependency eksternal.

## Fitur
- CRUD transaksi pemasukan & pengeluaran.
- Filter berdasarkan bulan, tipe, dan kategori.
- Budget limit per kategori dengan progress bar.
- Target tabungan dengan progress otomatis.
- Recurring transaction (mingguan/bulanan).
- Ringkasan metrik: saldo, total income/expense, saving rate.
- Grafik kategori berbasis canvas.
- Export/import data JSON.
- Persisten ke `localStorage`.

## Menjalankan
Buka `index.html` langsung di browser.
